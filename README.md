# Library Management System

A full-stack library management web application built with Spring Boot, React, TypeScript, and PostgreSQL.

## Features
- JWT authentication and role-based authorization
- Book catalog with search, filter, and pagination
- Borrow request workflow
- Admin approval and loan management
- Book return and fine tracking
- Reviews, notifications, and subscriptions
- Admin management for books, authors, categories, publishers, and users

## Tech Stack
Backend: Java 17, Spring Boot, Spring Security, JWT, Spring Data JPA, PostgreSQL  
Frontend: React, TypeScript, Vite, Tailwind CSS, Axios  
Database/DevOps: PostgreSQL, Docker Compose
